# MacLock для niri

MacLock запускается отдельно от основной оболочки и использует протокол Wayland session-lock. Имя установленной конфигурации — `MacLock-niri`.

Предварительный просмотр без блокировки:

```bash
MACLOCK_PREVIEW=1 qs -c MacLock-niri
```

Автоматическая offscreen-проверка того же production LockScreen: `python3 scripts/check-maclock-language.py`. Она переключает RU/EN через файл настроек и завершается ошибкой, если активировались настоящий lock или PAM. Физическая аутентификация этим скриптом не подтверждается.

После установки блокировка запускается через `~/.local/bin/maclock-niri`. Обёртка передаёт отдельный каталог настроек, запускает свежий экземпляр и вызывает IPC `lockscreen lock`. Повторный вызов при уже активной блокировке не создаёт второго locker.

Для запуска используются пользовательский systemd и `flock`: MacLock получает собственную службу и не завершается вместе со службой оболочки. При выходе из сеанса его служба останавливается вместе с композитором. При установке или откате требуется выйти из сеанса MacShell; установщик также не меняет файлы при активной либо недоступной для проверки блокировке.

PAM-служба по умолчанию — `/etc/pam.d/login`. Можно выбрать уже настроенную службу через `MACLOCK_PAM_SERVICE`. Hyprland и hyprlock не нужны; системные PAM-файлы установщик не изменяет. Перед использованием убедитесь, что выбранная PAM-служба позволяет разблокировать экран. Индикатор Caps Lock использует доступные LED-состояния ядра и может отличаться для виртуальных клавиатур.

## Отпечаток пальца

Если в fprintd записан хотя бы один палец (Settings → Security & Unlock), MacLock слушает сканер, пока экран заблокирован, — параллельно полю пароля. Совпадение разблокирует так же, как правильный пароль. Подсказка в поле: «Отпечаток или пароль»; под ним — «Проведите пальцем…» или «Приложите палец…» по типу сканера. Нераспознанный палец трясёт поле, введённый пароль не стирается. После 5 нераспознанных попыток MacLock перестаёт слушать сканер до конца этой блокировки и просит пароль. Если сканер занят, отключён или fprintd перезапустился (например, после сна), проверка перезапускается с паузой до минуты; пароль работает всё время.

MacLock обращается к fprintd по системной D-Bus через `fingerprint-operation-rust unlock` (как hyprlock), а не через PAM: системные файлы `/etc/pam.d` не меняются. Проверка разрешена polkit-правилом fprintd `net.reactivated.fprint.device.verify` для активного локального сеанса. Выключить можно переключателем **Разблокировка MacLock отпечатком** в Security & Unlock (ключ `lockFingerprint` в `macbar/settings.json`); изменение действует со следующей блокировки. Вход в систему после перезагрузки (SDDM) остаётся по паролю — как Touch ID на Mac после перезапуска; связки ключей (gnome-keyring, KWallet) открываются только паролем.

Для проверки без настоящей блокировки: `MACLOCK_PREVIEW=1 MACLOCK_PREVIEW_FINGERPRINT=1 qs -c MacLock-niri` — совпадение пальца закроет предпросмотр.

Текущая раскладка клавиатуры отображается под полем пароля и на остальных мониторах. MacLock получает её от niri и обновляет при переключении; если связь с композитором потеряна, вместо прежнего значения отображается «Неизвестна».

Пример KDL для собственного сочетания:

```kdl
binds {
    Mod+Alt+L { spawn "/home/USER/.local/bin/maclock-niri"; }
}
```

Используйте свой абсолютный путь и свободное сочетание. Основной установщик также переводит существующий вызов Noctalia `lockScreen lock` на IPC MacShell `session lock`.
