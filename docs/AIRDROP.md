# AirDrop

Плитка **Control Center → AirDrop** открывает отдельное окно. **Enable for 10 minutes** включает приём и поиск на ограниченное время; **Stop AirDrop** завершает сессию. Закрытие окна сохраняет активную сессию, повторное нажатие плитки открывает её снова. После первого обновления плитка добавляется рядом с Screen Mirroring; последующее удаление через Edit Controls сохраняется.

Это совместимость с настоящим Apple AirDrop через [Owly](https://github.com/t4t5/owly), без приложения на iPhone и без облачного аккаунта. Нужны поддерживаемый Wi-Fi-адаптер, backend MacShell и его системная радиослужба.

**MacShell разрешает только Shared — режим без отключения обычного Wi-Fi.** Если адаптер требует Exclusive или Active monitor, кнопка запуска недоступна. Например, на текущем Intel AX201/AX211 AirDrop в MacShell заблокирован: такой режим обрывает интернет и звонки.

## Передача и приём

1. Включите AirDrop в MacShell.
2. Для отправки выберите **Choose files…**, на iPhone включите **AirDrop → Everyone for 10 Minutes** и разблокируйте его. Нажмите **Find devices**, затем **Send to…**. Передача ожидает согласия на телефоне, после чего показывает прогресс. Cancel останавливает отправку; Delivered появляется после подтверждения доставки.
3. Для приёма выберите ноутбук в меню «Поделиться → AirDrop» на Apple-устройстве. MacShell покажет имя отправителя и содержимое запроса. Нажмите **Accept** или **Decline** в течение примерно 14 секунд. Без ответа запрос отклоняется. Файлы сохраняются в `~/Downloads/AirDrop`; ссылки показываются текстом и не открываются автоматически.

Первая версия отправляет выбранные локальные файлы, до 100 за одну передачу. Папки для отправки не выбираются. Приём требует отдельного подтверждения; устаревшее подтверждение не действует на новую сессию.

## Wi-Fi и AirPlay

Режим зависит от адаптера и определяется `owly doctor`. Shared сохраняет обычное подключение. Exclusive и Active monitor отбирают адаптер у Wi-Fi; на Intel это привело к реальному обрыву соединения и звонка при пробе. Эти режимы теперь запрещены в MacShell.

Запрет проверяется в окне, Python-сервисе и нативном worker до запроса аренды радио. Старый параметр `wifiConsent=true` не отменяет запрет. Неизвестный режим также не разрешается. Доступность установленного backend (`configured`) отделена от разрешения запуска (`canStart`).

В разрешённом Shared-режиме Stop, истечение 10 минут, выход из оболочки и потеря владельца освобождают радиослужбу. Сессия ограничена 10 минутами, включая текущую передачу: для большого файла запустите новую сессию заранее.

MacShell требует остановить AirPlay перед включением AirDrop и блокирует начало AirPlay во время AirDrop. Оболочка не останавливает действующую трансляцию автоматически.

## Backend

Сборка из checkout, без установки и без переключения Wi-Fi:

```bash
bash scripts/build-airdrop-backend.sh
```

Нужны Rust/Cargo 1.88+, компилятор/линкер и зависимости [Owly](https://github.com/t4t5/owly). Используется закреплённая версия и небольшой [JSON-адаптер](../native/owly/README.md). Обычная версия CLI без этого адаптера не подходит.

Для Arch/CachyOS подготовлен [PKGBUILD](../native/owly/PKGBUILD) с системной службой, D-Bus/polkit, настройками виртуального интерфейса NetworkManager и лицензией. Сборка пакета из подготовленного дерева:

```bash
cd native/owly
MACSHELL_OWLY_TREE=/absolute/path/to/build/owly/source makepkg --nodeps --nocheck
```

Просмотрите пакет и установите его обычным пакетным менеджером. Установка QML сама по себе не устанавливает root-службу. На других дистрибутивах используйте описанный в [адаптере](../native/owly/README.md) layout upstream с сохранением лицензий и происхождения сборки.

При активном UFW приёму требуется отдельное правило для AWDL, а не для обычной Wi-Fi-сети:

```bash
sudo ufw allow in on awdl0 proto tcp from fe80::/10 to any port 8771 comment 'MacShell AirDrop'
```

MacShell не меняет firewall при включении AirDrop. Для удаления разрешения выполните ту же команду с `ufw delete allow`. Проверка возможностей: `owly doctor --json`; открытие окна: `macshell-niri ipc call airdrop open`.

Пользовательский worker в `~/.local/share/macshell-niri/runtime/bin/owly` имеет приоритет перед PATH (с учётом `XDG_DATA_HOME`). При обновлении worker сохраняйте лицензию, адаптер, исходную ревизию и контрольную сумму в `runtime/share/doc/owly`.

## Проверки

Протокол владельца сессии проверяется Python-фикстурами без радио, окно — QML-тестами в обеих темах. Отдельные Python/Rust-регрессии проверяют запрет опасных и неизвестных режимов до захвата радио; старое согласие не разрешает Exclusive/Active monitor. [Нативная проверка](../scripts/check-airdrop-native.py) передаёт настоящий файл через TLS в отдельном network namespace, проверяет отказ, устаревший ответ, прогресс и контрольную сумму. Она не заменяет проверку физического iPhone на адаптере с Shared. Воспроизведение — `bash scripts/preview-airdrop.sh`.
