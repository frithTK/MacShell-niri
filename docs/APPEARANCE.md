# Светлая и тёмная тема

**Settings → Appearance**, плитка Dark Mode в Control Center и пункт View → Dark Mode переключают одну тему для панели, Dock, Settings, Clock и наследующих виджетов. Уже открытые окна обновляются сразу. При запуске начальное значение берётся из настроек Dock/Settings после загрузки обоих прежних файлов; изменения из панели также сохраняются в обоих файлах. Сброс остальных настроек и смена формата не нужны.

Явные стили Light/Dark у Clock и Player и локальный режим Calendar сохраняют своё оформление. Liquid следует общей теме. У Weather Normal сохраняется цветное небо; Liquid меняет подложку, текст, стрелку местоположения, почасовые/дневные данные и значки вместе с темой.

## Вид стекла

В Appearance и Menu Bar сегменты **Вид стекла** переключают Прозрачное, Обычное, Живое и Матовое. Это готовые сочетания размытия, тонировки и преломления; именные варианты не опускают стекло в половинное разрешение. Выбранный вид применяется целиком и сохраняется между запусками. Если значения не совпадают ни с одним видом, подпись становится «Своё». Точные слайдеры размытия, преломления и тонировки открываются через **Дополнительно**.

`macshell-niri ipc call glass preset standard` применяет обычный вид. `glass state` показывает поле `look`.

## Прозрачная панель

При включённом Auto Contrast полностью прозрачная панель выбирает светлый или тёмный текст по яркости фона отдельно для каждого output. Поэтому над тёмными обоями текст может оставаться светлым и при светлой теме меню. Фон `0` и отключённая стеклянная полоса сохраняются: для исправления читаемости не требуется делать панель непрозрачной.

Проверка фона выполняется при запуске, смене темы/геометрии, обоев, фокуса, рабочего стола и полноэкранного состояния. Постоянного опроса нет; `grim` и ImageMagick обрабатывают только полосу панели, снимки не записываются. Небольшой гистерезис предотвращает колебания на сером фоне. Это реакция на события оболочки, а не анализ каждого кадра анимированных обоев или видео.

Светлое стекло имеет минимальную тонировку для читаемого текста над тёмными окнами. Параметр Translucency продолжает менять плотность материала. Цвета подложки и основного текста переключаются без независимого перехода через нечитаемые промежуточные оттенки. Старый результат анализа фона после смены темы не применяется.

## Диагностика и проверки

```bash
macshell-niri ipc call appearance state
macshell-niri ipc call appearance theme light
macshell-niri ipc call appearance theme dark
```

`state` читает текущую тему и состояние подбора текста на каждом экране. Две команды `theme` явно переключают и сохраняют выбранную тему.

`bash scripts/check-qml.sh` проверяет порядок загрузки настроек, переключения из обоих владельцев, повторные циклы, наследование/явные стили, контраст светлого материала и пиксели перерисованной стрелки Weather.

`python3 scripts/check-theme-native.py` в настоящем niri использует отдельную оболочку, временные настройки, недоступные D-Bus/niri endpoints и свои поверхности. Проверяются Settings/Control Center/View, уже открытые Activity/Bar Layout/Widgets/Clock, запись темы в оба файла, поздние результаты анализа фона и прозрачная панель над собственными чёрной/белой подложками. Тест не меняет пользовательскую тему и не управляет устройствами. `--capture-dir /path` сохраняет демонстрационные снимки. Физически проверен один монитор; логика и состояния текста разделены по outputs.
