# Раскладка меню-бара

Откройте **Settings → Menu Bar Items** или **Menu Bar → Arrange…**. Поиск понимает `элементы`, `порядок`, `раскладка`, `монитор`.

1. Перетащите элемент в **Left / Center / Right**. Чтобы вставить его между соседями, отпустите над левой или правой половиной нужного элемента.
2. Нажмите на элемент: появятся выбор зоны, стрелки порядка и **Hide**. Кнопка **+ Add item** возвращает скрытые элементы или добавляет **Space** — промежуток.
3. Нажмите **Apply** сверху. **Cancel** отменяет весь черновик.

Скрытый элемент сохраняет своё положение и параметры. Промежуток удаляется; через Add item можно добавить несколько новых. С клавиатуры: Tab выбирает элемент, Enter/Space открывает его действия, ←/→ меняют порядок, Delete скрывает. Выбор зоны и список добавления также доступны с клавиатуры.

## Дополнительные настройки

В **More options** находятся отдельные раскладки экранов, приоритет выбранного элемента, ширина промежутка, предпросмотр и **Reset this layout**. Для обычной перестановки элементов открывать этот раздел не требуется.

По умолчанию редактируется **All displays**. Для отдельного экрана выберите его в **Display** и нажмите **Create separate layout**. **Use all-displays layout** возвращает наследование общей раскладки. Отключённые экраны остаются в списке как **saved profile**. Если совпадают несколько профилей, **Use saved layout** позволяет выбрать нужный.

**Apply** сохраняет весь черновик, включая изменения для других экранов. **Reset this layout** сбрасывает только выбранную раскладку; глобальный Reset MacShell также сбрасывает профили экранов. При конфликте с другим редактором Apply блокируется до **Reload**, черновик остаётся доступным для просмотра.

## Что происходит при нехватке места

Предпросмотр использует тот же расчёт ширины, что панель, с демонстрационными размерами блоков. Он учитывает масштаб блоков, выбранный в Menu Bar. Для подключённого экрана подставляется его логическая ширина; поле **Screen width** в More options позволяет проверить другой размер. Предпросмотр не открывает приложения трея и не включает измерения или устройства.

Сначала сокращаются блоки с меньшим приоритетом: меню приложения показывает название с раскрывающей стрелкой, Workspaces — текущий стол, Activity — компактные значки или один индикатор, Clock — время. В компактном меню приложения через стрелку доступны File, Edit и остальные пункты. Затем блоки с меньшим приоритетом переходят в меню **•••**. Трей переносится целиком; его элементы сохраняют обычные действия, включая правую и среднюю кнопку. Громкость и раскладка клавиатуры сохраняют прокрутку в overflow.

Левая и правая зоны находятся у краёв. Центр располагается в середине экрана, пока есть место; затем смещается между боковыми зонами. Если минимальные формы не помещаются, остаётся overflow. Отключённые и недоступные по оборудованию блоки не занимают место. При полностью пустой панели Settings доступны через IPC:

```bash
~/.local/bin/macshell-niri ipc call settings pane barlayout
```

Батарея, клавиатура, приватность и Control Center учитывают доступность соответствующей функции. Privacy — самостоятельный блок; отключение его значков не скрывает сведения о приватности внутри Control Center. Меню следуют фактическим координатам кнопки на том же экране; при исчезновении блока или экрана меню закрывается.

Примеры с демонстрационными данными: [тёмная тема](images/bar-layout-dark.png), [светлая тема](images/bar-layout-light.png).

## Сопоставление экранов

Профиль хранит имя разъёма и доступные make/model/serial. Сначала проверяется совместимый экран на том же разъёме. При смене разъёма автоматическое сопоставление по serial разрешено только для единственного подходящего сохранённого и подключённого устройства. Одинаковая модель без serial сама по себе не объединяет мониторы. При неоднозначности применяется общая раскладка; **Use saved layout** явно привязывает выбранный профиль к экрану. Без serial одинаковые устройства на одном разъёме нельзя надёжно различить — проверьте профиль вручную.

Отключение экрана сохраняет его профиль и черновик. Если выбранный экран пропал во время редактирования, редактор переключается на общую раскладку; сохранённый профиль доступен в списке. Размеры и позиции считаются в логических пикселях. Физические пиксели, transform и scale остаются отдельными данными niri; отрицательные координаты и порядок списка выходов не меняют идентичность профиля.

## Хранилище и диагностика

Единственный писатель — `BarPreferences` / `bar_layout_service.py`. Файл: `macbar/layout.json` внутри `MACSHELL_SETTINGS_HOME`, затем `XDG_CONFIG_HOME`, затем `~/.config`. У установленной оболочки это `~/.config/macshell-niri/settings/macbar/layout.json`.

До первой записи видимость берётся из прежних `barWidgets`, `showTray` и `showSearch`; порядок прежнего массива не интерпретируется как порядок отображения. Старые поля остаются для совместимости снимков, новые редакторы работают через одного владельца раскладки. Обновление не записывает раскладку при простом чтении. Файл сохраняет общую раскладку, независимые профили экранов и явные привязки; неизвестные поля и типы блоков сохраняются. Неизвестные блоки показываются в редакторе как unavailable и не занимают место на панели.

Запись использует общую с Activity реализацию атомарной замены, ревизии, проверки содержимого и резервных копий. Предыдущий файл — `layout.previous.json`; миграция и подтверждённое восстановление создают отдельные копии. Повреждённый файл не заменяется автоматически; файл будущей версии доступен без перезаписи. Приоритеты, singleton-блоки, ID, зоны, размеры разделителей и профили повторно проверяются сервисом перед записью.

```bash
~/.local/bin/macshell-niri ipc call bar layout
```

Команда возвращает локальные координаты блоков, ширины, компактные формы и overflow по каждому подключённому экрану; настройки не меняет. Каталог встроенных блоков: [bar_catalog.json](../MacShell/bar_catalog.json).

Автоматизированы ширины 800/1366/1920, масштаб 100/125/150%, длинные заголовки, динамическая ширина трея, конфликт редакторов, пустые переопределения, сохранение отключённых профилей и неоднозначные устройства. `python3 scripts/check-bar-native.py` дополнительно проверяет нажатия меню в трёх зонах и компактное меню в короткоживущей панели Wayland с отдельными настройками и отключёнными системными D-Bus-сервисами. Этот тест проверяет геометрию и события, а не доступность реального оборудования. Несколько физических мониторов и меню реальных приложений трея требуют отдельной проверки на соответствующем оборудовании.
