# Установка и настройка

[О проекте](../README.ru.md) · [English](INSTALL.md)

## Зависимости

Нужны `niri` 26.04+, Quickshell с Wayland, PipeWire, Mpris, SystemTray, Notifications, UPower и BackgroundEffect; Qt 6.9+ Declarative, Wayland, SVG, ShaderTools. Для MacLock нужны также модули Pam и session-lock. Специальный модуль Quickshell.Niri не используется.

Для превью нужны `python` 3.11+, `python-gobject`, `python-pillow`, `gst-python`, GStreamer с элементами `pipewiresrc`, `capssetter`, `videoscale`, `videoconvert`, `appsink`, а также PipeWire и D-Bus ScreenCast в сессии niri. В Arch/CachyOS это обычно `gst-plugin-pipewire`, `gst-plugins-base` и `gst-plugins-good`. Проверка:

```bash
bash install.sh --check
```

Дополнительные возможности: `grim`, `wl-clipboard`, `wtype` для меню приложений и вставки, `cliphist`, `wf-recorder`, `brightnessctl`, `nmcli`, `wlsunset`, `jq`, `inotify-tools`. Для новых Wi-Fi/Bluetooth-контролов нужны NetworkManager/BlueZ и Gio из `python-gobject`; для режимов питания — power-profiles-daemon или совместимый D-Bus сервис. Для записи — `wf-recorder` и `ffprobe` из ffmpeg; для области — `slurp`, для выбора звука — `pw-dump`. Поддерживаются Linux-сборки recorder, связанные с библиотеками PipeWire либо PulseAudio; для PulseAudio backend нужны `pipewire-pulse` и `pactl`. Для смеси — `pw-loopback` и рабочая политика соединений PipeWire. Для видеообоев — `mpvpaper` и `ffmpeg`. Без программы соответствующая дополнительная функция недоступна; превью без рабочего захвата заменяются значками приложений.

Night Shift требует `wlsunset` в PATH оболочки и поддержки gamma-control композитором. Отдельный автозапуск, геолокация и расписание не нужны. Пользовательский каталог `~/.local/share/macshell-niri/runtime/bin` доступен оболочке при использовании находящегося там runtime Quickshell; проверка зависимостей учитывает его. Оценки батареи и доступные режимы питания зависят от оборудования и системных служб.

Установщик не вызывает пакетный менеджер. Если проверка сообщает о несовпадении версий Qt и Quickshell, используйте совместимую сборку. Отдельный runtime в `~/.local/share/macshell-niri/runtime/bin/qs` выбирается автоматически; `MACSHELL_QS_BIN` задаёт другой путь. Он не заменяет системный `qs`, используемый Noctalia. После обновления Qt runtime тоже может потребовать пересборки; проверка перед входом обнаружит несовместимость.

## Резервная копия

До установки сохраните текущий рабочий стол:

```bash
umask 077
python3 scripts/desktop_snapshot.py
```

Снимок в `~/.local/share/macshell-niri/snapshots/` содержит настройки niri, Noctalia, Quickshell и оформления, исходники порта, список пакетов и справочные копии системных файлов. Контрольные суммы проверяются сразу. Это резервная копия конфигурации рабочего стола, а не образ диска.

Для восстановления запустите `bash /путь/к/снимку/restore.sh` от обычного пользователя. Перед заменой файлов скрипт сохраняет их текущее содержимое в `pre-restore-*/`. Системные файлы он не меняет.

## Два варианта на экране входа

Команды установки выполняются из каталога проекта, без `sudo`, кроме регистрации пункта SDDM.

```bash
# Проверить будущие пути и копию вашей конфигурации niri:
bash install.sh --dry-run --session

# Подготовить второй профиль, не переключая текущий рабочий стол:
bash install.sh --session

# Проверить готовый профиль и совместимость Quickshell:
~/.local/bin/niri-macshell-session --check
```

Для SDDM нужен один системный шаг:

```bash
sudo bash ~/.local/share/macshell-niri/session/register-session.sh
```

После выхода из сеанса выберите **Niri** для нынешней Noctalia или **Niri (MacShell)** для новой оболочки. Перезапуск SDDM и перезагрузка не требуются. Регистрация добавляет только `/usr/local/share/wayland-sessions/niri-macshell.desktop` и `/usr/local/bin/niri-macshell-session`; файл обычной сессии не меняется.

Второй профиль копирует дерево `~/.config/niri` в `~/.config/macshell-niri/niri`, переводит существующие IPC-вызовы Noctalia на MacShell, добавляет отсутствующие сочетания и правила только для собственных окон. Конфликтующие сочетания сохраняются. Настройки вывода, раскладки и анимаций остаются в копии. Позднейшие правки основной конфигурации автоматически в неё не переносятся.

Профиль запускается отдельной службой `niri-macshell.service` с явным `--config`. Обычная `niri.service` и исходный `~/.config/niri/config.kdl` остаются прежними. Если предварительная проверка или запуск службы не проходят, выполняется очистка сессии и запускается обычная Niri. Служба проверяет подключение оболочки к композитору в течение 15 секунд; ожидание старта всей службы ограничено 30 секундами.

Установленные конфигурации: `MacShell-niri`, `MacLock-niri`. Настройки хранятся отдельно в `~/.config/macshell-niri/settings`; журнал новой сессии: `journalctl --user -b -u niri-macshell.service`. Ошибки до старта композитора сохраняются в `~/.local/state/macshell-niri/session.log`. Поддерживаются XDG-пути.

## Если после перезахода сломалось оформление Noctalia

В Qt 6.12 появился встроенный `QtQuick.Color`, который перекрывает `Commons/Color.qml` в установленной Noctalia 5.2.1. Признаки в `/run/user/$(id -u)/quickshell/by-pid/<PID>/log.log`: `Unable to assign [undefined] to QColor`, ошибки `smartAlpha`, `adaptiveOpacity` или `resolveColorKey` у `QQuickColor`. В этом случае восстановление старых настроек не устраняет конфликт типов.

Временный обход до совместимого обновления Noctalia:

```bash
python3 scripts/repair_noctalia_qt612.py         # показать план
python3 scripts/repair_noctalia_qt612.py --apply # сохранить копию и исправить импорты
```

После этого выйдите и выберите обычную **Niri**. Скрипт копирует системную оболочку в `~/.config/quickshell/noctalia-shell`, ограничивает импорты QtQuick версией 6.11 в этой копии и пользовательских плагинах. Настройки и системные файлы он не меняет. Резервная копия и команда отмены выводятся после выполнения; перед отменой сохраняются более поздние файлы. Пользовательская копия имеет приоритет над системной: после обновления Noctalia отмените обход, чтобы получать изменения пакета.

Предупреждение `noctalia-qs was built against Qt 6.11.2 ... Qt 6.12.0 without rebuilding` — отдельная несовместимость двоичного пакета. Для её устранения нужен `noctalia-qs`, пересобранный под установленную Qt. Runtime MacShell не заменяет его: Noctalia использует дополнительные модули Quickshell.Niri/Hyprland/I3/DWL.

## Переключение внутри текущей сессии

Альтернативный режим `bash install.sh --activate` переключает текущий рабочий стол. Для выбора при входе он **не нужен**. Команда без аргументов только устанавливает файлы.

Корневой `~/.config/niri/config.kdl` заменяется коротким include этой копии; исходные `cfg/*.kdl` не редактируются. Перед переключением выполняется `niri validate`, создаётся резервная копия, затем останавливается Noctalia и запускается MacShell. При ошибке запуска конфигурация восстанавливается. Другие оболочки и системные службы установщик не останавливает.

## Откат

Чтобы вернуться к прежнему виду, достаточно выйти из сеанса и выбрать **Niri**. Чтобы убрать второй пункт, выполните из обычной сессии:

```bash
sudo bash ~/.local/share/macshell-niri/session/register-session.sh --remove
```

Затем отмените последнюю установку пользовательских файлов:

```bash
bash install.sh --rollback
```

Восстанавливаются предыдущие файлы и конфигурация niri, а после активации из Noctalia запускается её прежняя конфигурация. Текущее содержимое заменённых каталогов сохраняется в `after/` внутри резервной копии. Копии лежат в `~/.local/share/macshell-niri/backups/`.

Если после установки вручную изменён корневой `config.kdl`, автоматический откат останавливается, сохраняя правки. Сначала сравните его с копией; `--rollback --force` разрешает восстановление поверх этих изменений. Повторные установки имеют отдельные снимки. Автообновление из upstream отключено, чтобы оно не заменило порт исходной версией.

## Обновление установленной оболочки

Выйдите из Niri (MacShell), выберите другой сеанс и выполните в каталоге checkout:

```bash
git pull --ff-only
bash install.sh --check
bash install.sh
```

Обновляются установленные файлы оболочки, MacLock и команды запуска. Настройки и существующий профиль niri сохраняются; создаётся новая резервная копия для отката. Установка и откат не выполняются во время активного сеанса MacShell или если MacLock занят либо его состояние нельзя проверить. Для обновления systemd-служб отдельного сеанса и команды входа используйте вместо этого `bash install.sh --session`: отдельный профиль niri будет заново сформирован из существующей конфигурации niri. Повторная регистрация SDDM и `--activate` для обычного обновления не нужны. Отдельно установленные программы runtime, включая `wlsunset`, не входят в Git checkout.

## Горячие клавиши и IPC

Шаблон — [config/macshell.kdl](../config/macshell.kdl). Включаются только свободные сочетания:

| Сочетание | Действие |
|---|---|
| Mod+Space | Spotlight |
| Mod+V / Mod+Period | Буфер обмена / Emoji |
| Mod+Shift+C | Control Center |
| Alt+Tab / Alt+Shift+Tab | Переключение приложений; отпускание Alt подтверждает выбор |
| Print | Выделение области для снимка |
| Mod+Ctrl+W | Обои |

Существующие мультимедийные сочетания Noctalia переводятся на IPC MacShell. Ручной пример:

```bash
~/.local/bin/macshell-niri ipc call settings open
~/.local/bin/macshell-niri ipc call status state
~/.local/bin/macshell-niri ipc call glass captures false
```

Полный список команд, параметров и диагностических ответов — в [справочнике IPC](IPC.md).

## Раскладка меню-бара

В **Settings → Menu Bar Items** элементы перетаскиваются между тремя зонами. По нажатию доступны стрелки порядка и Hide; **+ Add item** возвращает скрытые элементы. Apply/Cancel находятся сверху, приоритеты, предпросмотр и отдельные раскладки экранов — в **More options**; при нехватке места используются компактные формы и меню **•••**. Подробнее — [редактор панели](BAR_LAYOUT.md).

## Галерея виджетов

В **Settings → Widgets → My widgets** перечислены размещённые и неразмещённые карточки, включая отключённые экраны. Выберите экземпляр, чтобы изменить размер/стиль, создать независимый дубликат, перенести на другой экран или удалить с **Undo removal**. **Add widgets** открывает каталог Weather, Calendar, Clock и Player с демонстрационными S/M/L preview. Общие параметры погоды находятся в **Shared weather settings**.

Переключатель в заголовке Widgets скрывает карточки с сохранением раскладки и останавливает ненужные запросы и обновления. Таймеры и будильники Clock продолжают работать. В **Appearance… → Seconds** у Clock доступны плавный, посекундный и скрытый индикатор; карточки и отражения используют один источник времени.

**Appearance…** настраивает тему и шрифт с наследованием оболочки, размер текста, а для Player — плотность и тонировку. Предпросмотр работает с локальным черновиком; **Apply** сохраняет его одной операцией, **Cancel** отменяет, **Reset appearance** возвращает наследование после Apply. Размер, основной стиль и перенос сохраняются сразу. Неизвестные поля и прежние настройки сохраняются; конфликты записи не перезаписывают свежие данные.

**Arrange…** открывает управление на рабочем столе. Нажмите карточку для выбора, используйте **Configure…**, Duplicate, размер, перенос, Remove или Undo; завершите через **Done** или **Escape** в окне управления. Подробнее — [галерея и оформление виджетов](WIDGETS.md).

Области ввода следуют видимым интерактивным карточкам без ограничения в четыре Player. Фон и пассивные карточки пропускают клики; в режиме редактирования перетаскивание получает приоритет перед воспроизведением.

Раскладка хранится с версией, привязкой к экрану и желаемыми позициями. Старые записи мигрируют с резервной копией; отключение экрана и временная нехватка места не стирают раскладку. Запись атомарная, ошибки и восстановление доступны в галерее.

## Оформление Activity

В **Settings → Activity Monitor** доступны пороги CPU/ОЗУ, цветные или монохромные значки, порядок показателей и единицы скорости. Предпросмотр использует демонстрационные данные; Apply сохраняет изменения, Cancel отменяет черновик. Поиск находит отдельные параметры, в том числе по русским словам. Подробнее — [настройки Activity](ACTIVITY_SETTINGS.md).

## Liquid Glass и Intel iGPU

Стекло использует шейдерное преломление, когда niri сообщает координаты видимых окон. Для плиточных окон без координат используется живое размытие композитора с `xray false`, чтобы показывать окна под панелью. Это отдельный режим без линзового преломления; необходимы niri 26.04+ и Quickshell с BackgroundEffect. Подробнее — [фон стекла](CONTROL_CENTER.md#фон-стекла-в-niri).

В Settings → Menu Bar и Appearance ползунок Blur управляет реальной силой размытия. Настройка niri общая и влияет на другие приложения с фоновым размытием; ноль снимает размытие с поверхностей MacShell. Refraction доступен только при работающей линзе, иначе подпись объясняет ограничение. [Сравнение эффектов](images/glass-tuning.png) и [описание настроек](CONTROL_CENTER.md#оформление).

Геометрия поступает по постоянному IPC-подключению; опрос окон на 60 Гц убран. Превью разделяются между компонентами, по умолчанию ограничены 512 пикселями по длинной стороне, 5 кадрами/с и шестью потоками. `MACSHELL_CAPTURE_WIDTH` задаёт предел обеих сторон с сохранением пропорций; маленькие кадры не увеличиваются. Неиспользуемые потоки приостанавливаются, затем закрываются; во время записи и Game Mode захват выключается. Пример экономного запуска:

```bash
MACSHELL_CAPTURE_FPS=3 MACSHELL_CAPTURE_WIDTH=384 MACSHELL_CAPTURE_LIMIT=4 ~/.local/bin/macshell-niri
```

Параметры драйвера Intel и системный графический стек не изменяются.

## Особенности niri

niri не предоставляет Hyprland special workspaces и закрепление окна на всех столах. Hide/Minimize перемещают окно на фоновый рабочий стол, закрепление убрано. Геометрия стеклянной подложки следует IPC; промежуточные кадры compositor-анимаций могут отличаться. Fullscreen в niri 26.04 определяется по геометрии, поскольку явного флага в API окон нет.

MacLock использует PAM-службу `login`, либо `MACLOCK_PAM_SERVICE`; перед использованием проверьте preview и разблокировку в своей сессии. Не изменяйте `/etc/pam.d` ради установки оболочки. Подробности: [MacLock/README.md](../MacLock/README.md).
