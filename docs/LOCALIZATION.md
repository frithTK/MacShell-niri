# Язык системы и регион

В **Settings → Language & Region** (также ссылка в General) выбираются **Русский / English / System default**. Основной выбор задаёт язык оболочки и установленную locale приложений; язык приложений и региональные форматы можно затем изменить независимо.

После **Apply** собственные окна переключаются сразу: Settings, панель, Dock, Spotlight/Apps, Пункт управления, диалоги, редакторы/виджеты, Calculator/Currency, Clock и MacLock. Ввод/выделение, история и память калькулятора, таймер и черновики редакторов сохраняются. Для языка приложений и их служб нужен **выход из сеанса и новый вход**; настройка не завершает сеанс автоматически.

Регион задаёт Qt locale для чисел, дат, месяцев и дней недели. «Как в системе» использует форматы активного процесса; после нового входа они следуют новой locale. Явный регион меняет форматы собственных окон сразу. Раскладки, 12/24 часа и первый день недели остаются отдельными настройками. Язык учётной записи не меняет greeter или других пользователей. Стороннее приложение использует собственные переводы/переопределения языка. Пользовательские подписи, файлы/устройства, уведомления и музыкальные метаданные сохраняются; внешние технические диагностики могут оставаться в исходном виде.

## Сохранение и вход

Единственный документ — `~/.config/environment.d/90-macshell-locale.conf` (с учётом XDG_CONFIG_HOME). Комментарии содержат выбор UI/сеанса/региона, назначения — LANG/LANGUAGE/LC_MESSAGES и выбранные региональные LC_*. Одна атомарная замена публикует оба выбора. Права 0600; точная предыдущая версия сохраняется в `.conf.previous`.

В профиле **Niri (MacShell)** `session-locale.py` читает документ до запуска compositor и импорта окружения в user systemd/D-Bus. Так получают язык приложения, запускаемые через niri, оболочку и службы нового сеанса. Для других desktop launcher нужен тот же порядок: одной записи environment.d недостаточно, если launcher позже перезапишет окружение. [Область действия environment.d](https://www.freedesktop.org/software/systemd/man/latest/environment.d.html#Applicability).

Помощник проверяет `locale -a`, экспортирует только разрешённые переменные и не исполняет файл как shell. Чужой/повреждённый/будущий файл и symlink не перезаписываются. Token под постоянным sidecar lock защищает от двух редакторов; конфликт требует Reload. Удалённая locale остаётся видна как отсутствующая, чтобы её можно было заменить. Ошибка применения locale при входе сохраняет исходное окружение и записывает причину в журнал.

Без явного региона существующие региональные LC_* не перезаписываются. Непустой LC_ALL блокирует изменение языка приложений/региона с объяснением; UI можно менять отдельно. Окружение user manager может быть общим для нескольких сеансов одной учётной записи. Машинный `/etc/locale.conf` и PAM не редактируются.

## Каталог

Общий singleton `Locale/I18n.qml` и `TranslationState.qml` используют **1553 matching RU/EN ID** (проверка `scripts/check-translations.py`; также 1374 migrated literal calls). Каталог галереи виджетов держит английские `label`/`description`/`shared` в `WidgetCatalog.js`; UI берёт их через `I18n.legacy()`. `MacLock/Locale` ссылается на `MacShell/Locale` в исходниках; installer копирует каталог в самостоятельную конфигурацию MacLock. Upstream `lang/es.js` не подставлялся: это другой словарь поверх English keys, не замена `Locale/`. LocaleRuntime следит за файлом через FileView, без новых фоновых процессов и периодического опроса. Writer работает, пока открыт раздел языка.

Новые UI-тексты используют literal ID через `Language.I18n.text("language.title")` или `plural("notifications.more", count)`. Параметры именованные, подстановка однопроходная; результат — plain text, rich text отдельно экранирует значения. RU: one/few/many/other; EN: one/other. Missing translation получает English fallback, неизвестный ID — `⟦id⟧`. `legacy()` предназначен только для собственных метаданных/старых сообщений, не пользовательского текста.

ID, IPC, типы/размеры карточек, категории группировки и действия кнопок не зависят от перевода. Видимые подписи и accessibility локализуются, compositor titles Clock/Calculator/Settings сохраняют идентичность для Dock/floating rules. Alarm Save/Stop/snooze и графики используют постоянные коды. Поиск настроек сохраняет английские названия и русские слова; эмодзи ищутся на обоих языках. Числа хранятся канонически, локализуются результат/история/память/копирование Calculator.

Каталог использует Qt locale и не меняет глобальный Qt.uiLanguage: [этот API](https://doc.qt.io/qt-6/qml-qtqml-qt.html#uiLanguage-prop) сам по себе не поставляет отсутствующие переводы. Независимых словарей по окнам нет.

Русские названия/ключевые слова **2307 эмодзи, 282 валют и 419 exemplar cities** импортированы из Unicode CLDR 48, revision `acd6d88ae493633240e19a87a721076a8a75c310`; [лицензия](licenses/unicode-cldr.txt). При работе UI сеть для них не нужна. `scripts/import-cldr-locale.py` воспроизводит импорт из пяти файлов с SHA-256. Для 52 городов Clock есть отдельные подписи: Абу-Даби не заменяется Дубаем из-за общей зоны, Купертино остаётся Купертино.

## Проверки

- Portable: паритет/дубликаты RU/EN, формы, параметры, literal ID и тип вызова. Проверка каталога не заменяет визуальную приёмку.
- QML: fallback, реактивность, числительные, независимые форматы, черновики, ввод/история/память/копирование, контекст Clear/Volume, города и metric ID.
- `check-system-language-native.py --capture /tmp/language-preview`: настоящий выбор/Apply с временными файлами, другое открытое окно, все разделы настроек, поиск эмодзи, Save/snooze/Stop часов с запрещённым аудио, новый процесс с сохранённой русской locale.
- `check-maclock-language.py`: production LockScreen в offscreen preview, внешние атомарные обновления RU → EN → RU, сохранённое сообщение ошибки. Активная блокировка и PAM запрещены проверкой; физическую аутентификацию она не подтверждает.
- Native GUI-проверки запускаются последовательно; скриншоты и настройки используют демонстрационные данные.
