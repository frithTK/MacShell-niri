# Проверка планов от 26 октября 2026

Проверены исходный код, зависимости этапов и сценарии отказа. План исправлен до начала массового переноса UI. Этот документ описывает решения; готовность реализации отмечается отдельно в [прогрессе](CUSTOMIZATION_PROGRESS.md).

Результат: реализованы S00a и общий пользовательский срез S01/S02 — Language & Region, вся оболочка/MacLock и язык приложений следующего входа. [Состав поставки](LOCALIZATION.md). Управление сеансом S00b и независимый locker реализованы и проверены в изоляции; приёмка обычного входа/выхода ещё необходима.

| Найденный недочёт | Решение и критерий |
| --- | --- |
| Save, Stop/snooze и графики сравнивали английские подписи | Постоянные action/metric ID; проверены настоящие русские кнопки и графики. |
| Перевод категории приложений мог менять ключ группировки и скрывать приложения | Внутренние категории постоянны, отдельно переводится видимое имя. Английские названия сохраняются в поиске настроек. |
| Привязка города к exemplar city зоны подменяла Абу-Даби Дубаем, Купертино Лос-Анджелесом | Отдельные подписи всех 52 городов Clock; проверено сохранение реального имени в обоих языках. |
| Reload использовал снимок установленных locale при открытии окна | Реестр обновляется при каждом load/save; удалённая locale отклоняется, таймаут даёт код ошибки без записи. |
| Clear и Volume имеют разные значения в разных экранах | Контекстные ID: команда очистки/ясная погода, громкость/объём. Регрессии проверяют оба значения. |
| Клик уведомления удаляет delegate, затем вызывает его `dismiss()` | Удалить повторный вызов; native-регрессия нажимает настоящую карточку, включая синхронное закрытие действием. |
| Transient-служба ошибочно могла считаться завершённым автозапуском | S00 разделён на исправление уведомлений и постоянное управление сеансом. Вторая часть включает installer/rollback, вход/выход, защиту от двух экземпляров и rate limit рестартов. |
| MacLock запускается потомком shell | До постоянной службы проверить независимый lifecycle locker: stop/restart оболочки не должен завершать процесс в её cgroup вместе с активной блокировкой. Не перезапускать compositor ради UI. |
| Один переключатель языка мог выглядеть как готовая локализация | S01a — единое ядро, RU/EN-каталоги и тесты. S01b — все экраны и runtime-переключение с сохранением состояния. Публичный переключатель только после полной приёмки. |
| Перевод заголовков меняет Dock/floating identity | Постоянные ID/IPC и совместимость реестра окон исправляются до смены заголовков. |
| `LC_ALL` и общее окружение user systemd не учтены | Выявлять конфликт до записи; сначала поддержать язык следующего входа. Не обещать изоляцию общих D-Bus/systemd переменных по окнам. |
| Отпечаткам приписан импорт и абсолютная сохранность чужих шаблонов | Только методы fprintd для текущего пользователя/пальца; описать ограничения аппаратного GC. Никаких шаблонов в настройках MacShell. |
| Отмена PAM не защищала от запоздалого успеха | Привязать результат к поколению блокировки и действующему PAM-диалогу; физическая приёмка и пароль обязательны. |
| Наличие ИК-камеры могло считаться достаточным для Face unlock | Отдельно подтвердить backend, устойчивость к подмене и PAM. Отсутствие совместимого оборудования не блокирует остальные этапы. |
| Lock на заменяемом `clock.json` не исключает второго владельца | Постоянный sidecar `clock.lock`; тест с реальным atomic replace и двумя владельцами. |
| Повтор команды мог повторно запустить/сбросить таймер | Устойчивые UUID + payload hash + сохранённый результат, revision/CAS и session ID. |
| Не определены DST, пропуски, snooze и reboot | Явная календарная политика, окно catch-up 15 минут, kernel clock для длительностей, recovery с честным возрастом checkpoint. Нет обещания RTC-пробуждения. |
| Импорт песни не определял удаление/отмену/декодирование | Ограниченная проверка содержимого, согласованный каталог/файл, защита используемых записей и встроенный fallback. |
| Старый `trap 'kill 0'` может затронуть чужую process group | Проверить владение до переноса. Один audio owner; stop адресует только собственный запрос. Причиной прежнего исчезновения UI это не объявлено. |

Зависимости: S00a → S01a → S01b → S02; S00b отдельно до приёмки надёжного рестарта и MacLock. S03 начинается после основ локализации, фактическое включение требует участия пользователя. T23 использует исправленный [контракт времени](CLOCK_TIME_CONTRACT.md), затем U01.S2 и T24. U01.S1 можно готовить независимо от T23, но его каталог ещё не меняет звук работающего Clock. S04 остаётся самостоятельным исследованием оборудования. T25 первого цикла не ждёт неподдерживаемой камеры и не объявляет более поздние функции готовыми.
