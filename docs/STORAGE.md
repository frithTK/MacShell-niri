# Хранилище

**Settings → Storage** показывает смонтированные тома (общая / занятая / свободная ёмкость по `statvfs`) и по запросу обходит выбранные каталоги пользователя.

## Тома

Список берётся из `/proc/self/mountinfo`. Виртуальные ФС (proc, sys, tmpfs и т.п.) пропускаются. Повторные bind-монтажи того же устройства помечаются отдельно и не выдаются за второй диск. Если `statvfs` не удался, том остаётся в списке как недоступный. Дата измерения указана на странице.

## Обзор папок

Кнопка **Сканировать** обходит XDG-каталоги пользователя (Рабочий стол, Документы, Загрузки и др.), `~/.cache`, корзину и каталоги в `~/.local/share` / `~/.config`, имя которых совпадает с id существующего `.desktop` файла. Это **не** полная карта диска: сумма папок не равна занятому месту тома.

- Видимый размер файлов (`st_size`), не выделенные блоки CoW/sparse.
- Жёсткие ссылки считаются один раз.
- Симлинки не разыменовываются.
- Чужие точки монтирования и другие `st_dev` пропускаются.
- Обход можно отменить; лимит посещений и отказ в доступе помечают результат как неполный.

Крупные файлы и данные приложений открываются через «Показать в папке». Сведения о приложении идут в существующий desktop-source. Корзина открывается существующим окном Trash; с этой страницы ничего не удаляется.
