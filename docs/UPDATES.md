# Обновления

В **Настройки → Обновления** можно проверить MacShell и системные пакеты. Проверка запускается при открытии раздела и по кнопке «Проверить обновления».

Для MacShell показывается установленная версия и последний стабильный выпуск GitHub. Если выпуск новее, «Подготовить обновление» загружает отдельную копию с его тегом, не меняя текущую установку или рабочий каталог. После подготовки выйдите из Niri (MacShell), войдите в другой сеанс и выполните показанную команду. Штатный установщик сохранит резервную копию и не заменит файлы при активном сеансе MacShell или заблокированном MacLock. Для приватного репозитория нужны доступ к GitHub через `gh` для проверки и рабочая авторизация Git для загрузки.

Системные обновления проверяются через `checkupdates` в отдельной временной базе. Кнопка «Обновить систему…» открывает Kitty и запускает `sudo pacman -Syu`; список изменений и подтверждение остаются в терминале. Эта проверка охватывает репозитории pacman, но не AUR. На системах без pacman или `checkupdates` раздел сообщает, что проверка недоступна. Для запуска установки нужны Kitty и sudo.

При отсутствии сети, доступа к GitHub или репозиториям показывается ошибка проверки; такое состояние не означает, что обновлений нет. Автоматическая установка не выполняется.
