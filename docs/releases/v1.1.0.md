# MacShell-niri 1.1.0

This release brings local Notes and Reminders, a shared Clock service and a Timer widget to the niri desktop. It also adds Russian and English language settings and expands Calculator and desktop controls.

## Highlights

- Clock provides alarms, snooze, stopwatch and timer, with a shared service, recovery, sound selection and a desktop Timer widget. The sound library supports local imports, preview, favorites, per-alert volume and fading.
- Notes stores plain-text notes locally with search, autosave, undo, recovery of deleted notes and conflict copies.
- Reminders provides local lists and tasks, due times, notifications, recovery of deleted items and daily, weekly or monthly repeats after completion.
- Calculator includes basic and scientific modes, unit conversion, currency conversion and keyboard support.
- Language settings cover the shell and MacLock; session language changes apply to applications at the next login. Fingerprints can be managed through fprintd on supported hardware.

## Installation and updates

Follow the [installation guide](../INSTALL.md) or [Russian guide](../INSTALL.ru.md). Exit the current MacShell session before updating: the installer protects active sessions and lock state. Back up Notes and Reminders data separately; installer snapshots do not include their databases.

## Scope and checks

Python and QML regression suites and isolated niri, PipeWire and D-Bus checks passed. Acceptance of ordinary login, logout and password-based PAM unlock on an installed session has not yet been completed. Physical multi-monitor/hotplug and fingerprint-device acceptance also depend on available hardware. Fingerprint unlock in MacLock is not implemented.

Reminders notifications require its service to run and a working desktop notification service. Notes currently stores plain text without sync or attachments.

The sound library includes 65 recordings from a third-party archive described as macOS system sounds. Their provenance and permission to redistribute have not been independently confirmed; see [third-party notices](../../THIRD_PARTY_NOTICES.md). Personal imported audio and user databases are not included.
