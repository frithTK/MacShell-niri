# MacShell-niri 1.1.1

- Fixed Spotlight mouse selection when window information changes during a search. Pointer highlighting also follows the mouse immediately.
- Added an Updates section in Settings. It checks for stable MacShell releases and can prepare a separate checkout for installation after leaving the active session. On supported systems, it also checks pacman updates and can open the system update command in a terminal.

See the [installation and update guide](https://github.com/frithTK/MacShell-niri/blob/v1.1.1/docs/INSTALL.md) or the [Russian guide](https://github.com/frithTK/MacShell-niri/blob/v1.1.1/docs/INSTALL.ru.md). The installer protects active MacShell sessions and the lock state; exit the MacShell session before updating.

## По-русски

- Исправлен выбор результатов Spotlight мышью при обновлении сведений об открытых окнах. Подсветка теперь следует за указателем без задержки.
- В настройках появился раздел «Обновления»: он проверяет стабильные выпуски MacShell и подготавливает отдельную копию для установки после выхода из сеанса. На поддерживаемых системах также доступна проверка обновлений pacman и запуск обновления системы в терминале.

Инструкция по установке и обновлению: [INSTALL.ru.md](https://github.com/frithTK/MacShell-niri/blob/v1.1.1/docs/INSTALL.ru.md). Перед обновлением выйдите из сеанса MacShell.
