# MacShell-niri 1.1.2

- Added Stickies with compact floating windows, autosave, shared Notes storage and restoration of open windows and their geometry after a shell restart.
- Simplified Notes and Reminders controls with accessible icons; deleted reminders can be recovered from Recently Deleted.
- MacLock now shows the current keyboard layout; the Dock Trash icon now has bundled empty and full states.
- Refined built-in utility interfaces and fixed initial World Clock time-zone offsets.

To update, exit the active MacShell session first. See the [installation guide](https://github.com/frithTK/MacShell-niri/blob/v1.1.2/docs/INSTALL.md).

## По-русски

- Добавлены «Записки»: компактные плавающие окна, автосохранение и общее хранилище с «Заметками». Открытые окна, их размер и положение восстанавливаются после перезапуска оболочки.
- Упрощены кнопки в заметках и напоминаниях; удалённые задачи можно вернуть через «Недавно удалённые».
- MacLock показывает текущую раскладку клавиатуры; для корзины Dock добавлены встроенные значки пустого и полного состояния.
- Обновлён интерфейс встроенных приложений и исправлена первоначальная загрузка часовых поясов мировых часов.

Перед обновлением выйдите из сеанса MacShell. [Инструкция по установке](https://github.com/frithTK/MacShell-niri/blob/v1.1.2/docs/INSTALL.ru.md).
