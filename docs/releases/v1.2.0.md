# MacShell-niri 1.2.0

MacShell now includes a standalone Calendar app and new Rust services for Wi-Fi, Bluetooth, screen capture and recording, and desktop settings. Python fallback remains available during the transition.

This release also includes the Notes, Reminders, Stickies and MacLock improvements described in the 1.1.2 changelog.

The new services have been tested in isolated environments, including virtual audio and video sources. Testing with real devices and a normal login session is still pending.

To update, exit the active MacShell session first. Rust build and capture dependencies are listed in the [installation guide](https://github.com/frithTK/MacShell-niri/blob/v1.2.0/docs/INSTALL.md).

---

В MacShell появился отдельный Calendar, а службы Wi-Fi, Bluetooth, захвата и записи экрана и настройки рабочего стола переведены на Rust. На время перехода сохранён запасной вариант на Python.

Релиз также включает улучшения Notes, Reminders, Stickies и MacLock из списка изменений 1.1.2.

Новые службы проверены в изолированной среде, в том числе с виртуальными источниками аудио и видео. Проверка на реальных устройствах и при обычном входе в сеанс ещё впереди.

Перед обновлением выйдите из сеанса MacShell. Зависимости для сборки Rust и захвата перечислены в [инструкции по установке](https://github.com/frithTK/MacShell-niri/blob/v1.2.0/docs/INSTALL.ru.md).
